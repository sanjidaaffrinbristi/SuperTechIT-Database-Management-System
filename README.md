# SuperTechIT: Super Shop Database Management System 🗄️

An Oracle Database Management System designed for tech product retail operations, featuring ER modeling, schema normalization (3NF), relational queries, SQL views, and Java JDBC connection.

---

## 📌 Project Overview
**SuperTechIT** streamlines retail store operations by handling structured relational data across customers, employee roles, product categories, inventory stock, and suppliers.

- **Course:** Introduction to Database
- **Database Engine:** Oracle Database Express Edition (10g/XE)
- **Languages & Tools:** SQL, PL/SQL, Java (JDBC)

---

## 🏗️ Database Architecture & Normalization
The database design incorporates relational modeling up to **3rd Normal Form (3NF)**:
- **Core Entities:** `employee`, `customer`, `product`, `company`, `category`
- **Relationship Entities:** `orders`, `supply`, `handle`, `restore`, `list`

Refer to the complete ER diagrams and normalization steps in [`docs/SuperTechIT_Project_Report_Part_1.pdf`](./docs/).
